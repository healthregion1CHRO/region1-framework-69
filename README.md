# ระบบกรอกกรอบอัตรากำลัง ปี 2569 เขตสุขภาพที่ 1 (GitHub Pages + Google Apps Script)

ระบบมี 2 ส่วน

| ไฟล์ | วางที่ไหน | ทำหน้าที่ |
|---|---|---|
| `index.html` | GitHub Pages | หน้าเว็บ หน้า login และช่องกรอกกรอบ ปี 69 |
| `Code.gs` | Google Apps Script (ผูกกับ Google Sheets) | ตรวจรหัสผ่าน และเก็บตัวเลขที่แต่ละหน่วยงานกรอก |

รหัสผ่านเก็บเป็นค่าแฮชใน Google Sheets เท่านั้น **ไม่อยู่ใน GitHub**

---

## ขั้นที่ 1 สร้างหลังบ้าน (Google Sheets + Apps Script)

1. สร้าง Google Sheets ใหม่ เช่นชื่อ `ระบบกรอบ69 เขต1` (ไฟล์นี้คือฐานข้อมูล อย่าแชร์ให้คนอื่นแก้)
2. เมนู **ส่วนขยาย > Apps Script** ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจาก `Code.gs` กดบันทึก
3. เลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้** (ครั้งแรกจะขออนุญาต ให้กดอนุญาต)
   - ระบบสร้างชีต `Users`, `Units`, `Counts`, `Ucfg`, `Log` ให้
   - ชีต `Units` คือรายชื่อหน่วยงาน 728 แห่ง ใช้ดูชื่อที่ต้องสะกดให้ตรง

## ขั้นที่ 2 ใส่ผู้ใช้งาน (ชุดเดียวกับระบบคำขอใช้ตำแหน่งว่าง)

ในชีต `Users` กรอกทีละแถว

| คอลัมน์ | ใส่อะไร |
|---|---|
| username | ชื่อผู้ใช้เดิมของระบบคำขอใช้ตำแหน่งว่าง |
| password | รหัสผ่านเดิม (จะถูกลบทิ้งอัตโนมัติในขั้นถัดไป) |
| ชื่อหน่วยงาน | สะกดให้ตรงกับชีต `Units` เช่น `สสจ.แพร่`, `รพ.เชียงดาว` |
| จังหวัด | เช่น `แพร่` |
| role (admin/unit) | `unit` = เจ้าหน้าที่หน่วยงาน, `admin` = ผู้ดูแล (เห็นและแก้ได้ทุกหน่วยงาน) |
| ชื่อผู้ใช้ที่แสดง | ชื่อที่จะขึ้นมุมขวาบน (ไม่ใส่ก็ได้) |

จากนั้นเลือกฟังก์ชัน `hashPasswords` แล้วกด **เรียกใช้**
- คอลัมน์ password จะถูกล้าง เหลือเพียง password_hash และ salt
- คอลัมน์ unit_id ถูกเติมให้อัตโนมัติ ถ้ามีข้อความ "ไม่พบชื่อหน่วยงาน" ให้แก้ชื่อให้ตรงกับชีต `Units` แล้วรันซ้ำ
- เพิ่มผู้ใช้ใหม่หรือเปลี่ยนรหัสภายหลัง: ใส่ในคอลัมน์ password แล้วรัน `hashPasswords` อีกครั้ง

## ขั้นที่ 3 เปิดให้หน้าเว็บเรียกใช้ (Deploy)

1. ใน Apps Script กด **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่**
2. ประเภท: **เว็บแอป** · เรียกใช้ในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
3. กดทำให้ใช้งานได้ แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

> แก้ `Code.gs` ภายหลัง ต้องกด **จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชันใหม่** URL จะคงเดิม

## ขั้นที่ 4 ใส่ URL ในหน้าเว็บ

เปิด `index.html` ค้นหา `PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE` แล้วแทนด้วย URL จากขั้นที่ 3

```js
const API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

## ขั้นที่ 5 ขึ้น GitHub Pages

1. สร้าง repository ใหม่ใน GitHub (Public ได้ เพราะไม่มีรหัสผ่านในไฟล์)
2. **Add file > Upload files** อัปโหลด `index.html` แล้ว Commit
3. **Settings > Pages** · Source: **Deploy from a branch** · Branch: `main` / `(root)` กด Save
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`

## ขั้นที่ 6 ทดสอบ

- เข้าด้วยบัญชี `admin`: เห็นทุกแท็บ เลือกได้ทุกหน่วยงาน
- เข้าด้วยบัญชี `unit`: เปิดที่หน่วยงานของตัวเองทันที ช่องเลือกหน่วยงานถูกล็อก กรอกได้เฉพาะหน่วยงานตัวเอง
- ตัวเลขที่กรอกจะไปอยู่ในชีต `Counts` (มีคอลัมน์ผู้กรอกและเวลา) ประวัติ login อยู่ในชีต `Log`

## ข้อควรรู้

- **ความปลอดภัย:** ระบบหลังบ้านตรวจทุกครั้งว่าผู้ใช้แก้ได้เฉพาะหน่วยงานของตัวเอง ไม่ใช่แค่ซ่อนปุ่ม
- **ระบบคำขอใช้ตำแหน่งว่าง:** ถ้ารหัสผ่านของระบบนั้นอยู่ในไฟล์เว็บบน GitHub คนที่เปิดดูซอร์สจะเห็นรหัสได้ ควรย้ายไปใช้แบบเดียวกับระบบนี้ และเปลี่ยนรหัสผ่านทั้งหมด
- **การอัปเดตข้อมูล:** หน้าเว็บดึงข้อมูลใหม่ทุก 20 วินาที · อยู่ในระบบได้ 6 ชั่วโมงต่อการ login
- **โควตา Google:** Apps Script บัญชีทั่วไปรองรับการใช้งาน 23 หน่วยงานได้สบาย
